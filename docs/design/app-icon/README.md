# CPaste 图标设计方向

2026-09-29 用户在应用列表中比较后，选定实色双卡片方案，替换 0.4.4 使用的液态玻璃图标。

![实色双卡片](../../../Resources/AppIcon/AppIcon-1024.png)

## 当前设计

- 保留两张圆角卡片错位叠放的布局：后层偏左上、前层偏右下，两张卡片都略向左倾斜。
- 青绿底色、较深的青绿后卡片和实白前卡片，通过色块对比及轻阴影区分层次。
- 卡片保持空白，去掉透明叠层、折射和玻璃高光；优先保证应用列表中约 32–64 px 的辨识度。
- 菜单栏继续使用双卡片单色模板，由系统适配深浅背景。

## 文件与打包

- 选定原稿：`solid-cards-v1.png`，1254 × 1254，保留生成文件原始内容。
- 生产资源使用 `swift scripts/generate_app_icon.swift` 从原图裁切、应用抗锯齿透明蒙版并等比例缩放，生成 `Resources/AppIcon/AppIcon-1024.png`、完整 iconset 和 `CPaste.icns`。
- 裁切与蒙版向底板内部收进，排除原稿透明边缘的杂点。卡片布局、内部 RGB 颜色和阴影保持原稿，不再通过生成式编辑重绘。
- 生产底板保持严格正方形：1024 px 画布中居中放置 824 × 824 px 底板。先裁切背景为正方形再等比例缩放，不拉伸卡片。
- 原稿实色区域的 alpha 多为 252–254，系统应用列表仍会将其当作半透明图形，加上额外浅色底板并缩小。打包时保留直通 RGB 字节，只将内部 alpha 规范为 255，最后再应用外缘抗锯齿蒙版。验收同时检查应用内图标与 `NSWorkspace` 读取的已安装应用图标。
- 正式图标通过静态 `.icns` 提供，兼容 macOS 13 及以上版本。

## 生成来源

- 使用内置 imagegen 工具生成。
- 参考此前双卡片布局，以及用户提供的应用列表截图；应用列表仅用于判断小尺寸辨识度，不复制其他应用图标。
- 生成文件标识：`exec-32b850f6-4220-4ca4-bb2d-c01119870732.png`。
- 提示词要点：保留双卡片位置、大小、倾斜和重叠关系；改用不透明实色色块；青绿底、深青绿后卡片、实白前卡片；仅用短而轻的阴影区分层次；去掉玻璃透明、折射、模糊高光、厚倒角、文字与额外符号；适合 32–64 px 显示。

## 历史方向

`liquid-glass-v2.png` 是 0.4.4 的选定原稿，保留用于设计追溯。它对应明亮液态玻璃方向第二次草案，已由本次实色方案取代。此前两次生成式抠图因质量下降被弃用，不属于生产资源。
