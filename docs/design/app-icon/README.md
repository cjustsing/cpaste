# CPaste 图标设计方向

2026-09-29 用户选定明暗对比双卡片方案，替换 0.4.5 使用的亮青绿色实色图标。

![明暗对比双卡片](../../../Resources/AppIcon/AppIcon-1024.png)

## 当前设计

- 保留两张圆角卡片错位叠放的布局：后层偏左上、前层偏右下，两张卡片都略向左倾斜。
- 中等明度的灰青底色、深青蓝后卡片和柔白前卡片，通过中、深、浅三个明度层次及轻阴影区分层次。
- 卡片保持空白，采用不透明实色，避免荧光青绿、玻璃折射和强高光；优先保证工具栏与应用列表中约 24–64 px 的辨识度。
- 菜单栏继续使用双卡片单色模板，由系统适配深浅背景。

## 文件与打包

- 选定原稿：`contrast-cards-v2.png`，1254 × 1254，保留生成文件原始内容。
- 生产资源使用 `swift scripts/generate_app_icon.swift` 从原图裁切、应用抗锯齿透明蒙版并等比例缩放，生成 `Resources/AppIcon/AppIcon-1024.png`、完整 iconset 和 `CPaste.icns`。
- 裁切与蒙版向底板内部收进，排除原稿透明边缘的杂点。卡片布局、内部 RGB 颜色和阴影保持原稿，不再通过生成式编辑重绘。
- 生产底板保持严格正方形：1024 px 画布中居中放置 824 × 824 px 底板。先裁切背景为正方形再等比例缩放，不拉伸卡片。
- 原稿实色区域的 alpha 多为 252–254，系统应用列表仍会将其当作半透明图形，加上额外浅色底板并缩小。打包时保留直通 RGB 字节，只将内部 alpha 规范为 255，最后再应用外缘抗锯齿蒙版。验收同时检查应用内图标与 `NSWorkspace` 读取的已安装应用图标。
- 正式图标通过静态 `.icns` 提供，兼容 macOS 13 及以上版本。

## 生成来源

- 使用内置 imagegen 工具生成。
- 参考此前双卡片布局，以及用户提供的 CPaste 工具栏截图；截图仅用于判断小尺寸辨识度。
- 生成文件标识：`exec-9fe18f71-da91-47c1-ba53-1205d6cbf333.png`。
- 完整设计目标与生成提示词见[明暗对比双卡片设计记录](contrast-cards-v2.md)。

## 历史方向

- `solid-cards-v1.png` 是 0.4.5 的亮青绿色实色原稿，因小尺寸下亮色过多、后卡片与底色接近而被当前方案取代。
- `liquid-glass-v2.png` 是 0.4.4 的液态玻璃原稿。此前两次生成式抠图因质量下降被弃用，不属于生产资源。
- 历史原稿保留用于设计追溯，不再作为生产图像源。
