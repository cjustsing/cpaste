# CPaste 使用说明书

适用版本：CPaste `0.3.2 (5)`
适用系统：macOS 13 及以上  
处理器：Apple Silicon，当前交付包为原生 `arm64`

## 1. 产品简介

CPaste 是一个本地剪贴板历史应用。它常驻 macOS 菜单栏，自动记录文本、链接、文件和图片，并通过横向视觉时间轴帮助你搜索、预览、收藏和重新粘贴历史内容。

![CPaste 应用图标](../Resources/AppIcon/AppIcon-1024.png)

主要能力：

- 使用 `Shift-Command-V` 从任意应用呼出。
- 横向时间轴浏览，卡片显示内容类型、来源应用和内容预览。
- 即时搜索、历史/收藏切换和内容类型筛选。
- 鼠标、触控板、键盘、右键菜单和跨应用拖拽。
- 自动粘贴、纯文本粘贴，以及无权限时只复制到系统剪贴板。
- 历史记录只保存在本机，不包含账号、云同步或网络上传。

## 2. 安装与启动

### 2.1 构建应用

在项目根目录执行：

```sh
swift build -c release --arch arm64
./scripts/build_app.sh
```

应用生成在：

```text
build/CPaste.app
```

### 2.2 启动

```sh
open build/CPaste.app
```

CPaste 是菜单栏应用，启动后不会常驻 Dock。

### 2.3 验证 Apple Silicon 架构

```sh
file build/CPaste.app/Contents/MacOS/CPaste
lipo -archs build/CPaste.app/Contents/MacOS/CPaste
```

期望输出包含：

```text
Mach-O 64-bit executable arm64
arm64
```

## 3. 权限说明

| 行为 | 是否需要额外权限 |
| --- | --- |
| 记录系统剪贴板历史 | 不需要 |
| 把历史内容复制回系统剪贴板 | 不需要 |
| 自动切回上一个应用并发送 `Command-V` | 需要辅助功能权限 |

辅助功能权限路径：

```text
系统设置 -> 隐私与安全性 -> 辅助功能 -> 启用 CPaste
```

未授权时，执行“粘贴”仍会把选中内容复制回系统剪贴板；随后可在目标应用手动按 `Command-V`。

## 4. 界面总览

![CPaste 横向时间轴总览](screenshots/timeline-refactor/01-timeline-overview.png)

主窗口从上到下分为三层：

| 区域 | 组成 | 用途 |
| --- | --- | --- |
| 顶部命令栏 | CPaste 标识、历史/收藏、搜索、类型筛选、详情、暂停、设置、关闭 | 控制浏览范围和窗口状态 |
| 中央时间轴 | 固定尺寸内容卡片，可横向滚动 | 浏览、选择、粘贴和拖出历史内容 |
| 底部状态栏 | 捕获状态、当前来源应用、可见数量/总数量、权限状态 | 确认当前工作状态 |

### 4.1 顶部命令栏

从左到右：

1. `CPaste`：应用标识。
2. `历史 / 收藏`：切换全部时间记录与收藏内容。
3. 搜索框：打开面板后自动聚焦，输入时即时过滤。
4. 类型筛选：全部、文本、链接、文件、图片。
5. 详情按钮：展开或收起当前卡片的完整预览。
6. 捕获按钮：暂停或继续记录剪贴板。
7. 设置按钮：打开通用和隐私设置。
8. 关闭按钮：收起 CPaste。

### 4.2 时间轴卡片

每张卡片包含：

- 顶部色带：显示内容类型、复制时间、收藏状态和来源 App 图标。
- 中央预览：直接显示文本、链接、文件列表或图片。
- 底部信息：可见位置编号、来源应用和字符/行数、文件数或图片尺寸。
- 青绿色描边：表示当前选中卡片。

可见位置 `1` 到 `9` 同时对应 `Command-1` 到 `Command-9` 快速粘贴。

## 6. 打开与关闭 CPaste

打开方式：

- 按 `Shift-Command-V`。
- 左键点击菜单栏 CPaste 图标。
- 右键菜单栏图标，选择“显示 CPaste”。

关闭方式：

- 再按一次 `Shift-Command-V`。
- 按 `Escape`；若搜索框内有文字，第一次会先清空搜索，再按一次关闭。
- 点击右上角关闭按钮。
- 点击其他应用，浮动面板会自动收起。

每次重新打开面板时搜索词会清空、时间轴回到最左侧，并默认使用方向键选择卡片；历史/收藏和类型筛选会保持当前选择。

## 7. 搜索、范围与筛选

### 7.1 即时搜索

点击搜索框或按 `Command-F` 后输入，即可搜索以下内容：

- 条目标题与完整文本。
- 文件名和文件路径。
- 内容类型。
- 来源应用名称和 bundle id。

`Command-F` 可随时把焦点移回搜索框。

### 7.2 历史与收藏

- `历史`：按最近复制时间排列全部内容。
- `收藏`：只显示已收藏内容。
- 按 `Option-1` 切换到历史，按 `Option-2` 切换到收藏。

收藏不会改变历史时间顺序，也不会被“清空未收藏历史”删除。

### 7.3 内容类型筛选

类型菜单支持：

| 类型 | 内容 |
| --- | --- |
| 全部 | 所有受支持内容 |
| 文本 | 普通文本和多行文本 |
| 链接 | 带协议和主机名的 URL |
| 文件 | Finder 中复制的一个或多个文件 |
| 图片 | 剪贴板图片，以及聊天工具复制的单张 PNG、JPG 等临时图片文件 |

启用类型筛选后，搜索框内会显示可移除的类型标记。

## 8. 鼠标与触控板操作

| 操作 | 结果 |
| --- | --- |
| 单击卡片 | 选中卡片 |
| 双击卡片 | 粘贴卡片内容 |
| 横向滚动 | 浏览时间轴 |
| 悬停卡片 | 显示复制、收藏和删除快捷按钮 |
| 右键卡片 | 打开完整上下文菜单 |
| 拖动卡片到其他应用 | 以文本、URL、文件或图片格式复制内容 |

右键菜单会根据内容类型提供粘贴、纯文本粘贴、复制、打开链接/在访达中显示、收藏和删除。

## 9. 键盘操作

CPaste 可完整使用键盘操作：

| 快捷键 | 作用 |
| --- | --- |
| `Shift-Command-V` | 全局显示或隐藏 CPaste |
| `Command-F` | 聚焦搜索框 |
| `Option-1` / `Option-2` | 切换到历史 / 收藏 |
| `Tab` | 在搜索框和时间轴间切换焦点 |
| `←` / `↑` | 选择上一张卡片 |
| `→` / `↓` | 选择下一张卡片 |
| `Command-↑` | 选择第一张卡片 |
| `Command-↓` | 选择最后一张卡片 |
| `Return` | 粘贴选中内容 |
| `Shift-Return` | 粘贴为纯文本；图片不支持时给出状态提示 |
| `Command-1` … `Command-9` | 快速粘贴当前可见的第 1 … 9 项 |
| `Command-C` | 只复制选中内容到系统剪贴板 |
| `P` | 收藏或取消收藏选中内容 |
| `Space` | 展开或收起详情 |
| `Delete` | 删除选中内容 |
| `Command-T` | 暂停或继续捕获 |
| `Command-,` | 打开设置 |
| `Escape` | 清空搜索或关闭面板 |

当搜索框正在编辑时，左右键仍用于移动文本光标；按 `Tab` 或 `↓` 进入时间轴后，方向键用于选择卡片。

## 10. 复制、粘贴与打开

### 10.1 粘贴

执行粘贴后：

1. CPaste 把条目写回系统剪贴板。
2. 条目移动到历史最前方。
3. 有辅助功能权限时，CPaste 收起、切回上一个应用并发送 `Command-V`。
4. 无权限时，面板保持打开并提示“已复制”。

### 10.2 纯文本粘贴

- 文本和链接：去除其他格式，只写入字符串。
- 文件：写入换行分隔的文件路径。
- 图片：当前版本没有 OCR，不提供伪造的纯文本结果。

### 10.3 打开条目

- 链接：使用系统默认浏览器打开。
- 文件：在 Finder 中定位。
- 文本和图片：没有直接打开动作，可复制、粘贴或拖出。

## 11. 收藏与删除

收藏方式：

- 选中卡片后按 `P` 收藏或取消收藏。
- 卡片悬停后点击 pin 图标。
- 展开详情后点击 pin 图标。
- 在右键菜单中选择“收藏”。

删除单项：

- 按 `Delete`。
- 点击悬停或详情区的垃圾桶图标。
- 在右键菜单末尾选择“删除”。

删除选中卡片后，CPaste 会继续选中它前面的卡片；删除第一张卡片时则选中下一张，避免时间轴跳回开头。

清空未收藏历史：

- 打开设置 -> 隐私 -> 清理历史。
- 或右键菜单栏 CPaste 图标，选择“清空未收藏历史”。

清空操作会先确认，已收藏内容始终保留。

## 12. 设置

### 12.1 通用

| 设置 | 说明 |
| --- | --- |
| 剪贴板捕获 | 暂停时不保存新复制内容 |
| 历史容量 | 50、100、500 或 1000 条；收藏不受清理影响 |
| 呼出快捷键 | 显示 `Shift-Command-V` 是否注册成功 |
| 直接粘贴 | 显示辅助功能权限状态并可打开系统设置 |

### 12.2 隐私

隐私页显示：

- 所有数据仅保存在本机。
- 密码管理器标记、临时内容和自动生成内容不会进入历史。
- 历史文件在应用层未加密。
- 当前实际数据目录。
- 清空未收藏历史入口。

### 12.3 快捷键

快捷键页以“浏览”和“操作”两栏集中展示 CPaste 当前支持的全部快捷键，内容与第 9 章的键盘操作表保持一致。

### 12.4 关于与赞赏

“关于”页显示 CPaste 的版本、项目定位和 Apache-2.0 开源许可。点击“查看收款码”可在本地打开支付宝或微信赞赏二维码。

赞赏完全自愿，不会解锁任何功能，也不会影响软件使用、技术支持或后续更新。二维码图片随应用本地提供，CPaste 不会记录赞赏行为或为此发送网络请求。

## 13. 菜单栏

左键菜单栏图标用于显示或隐藏时间轴。右键菜单包含：

| 菜单项 | 作用 |
| --- | --- |
| 显示 CPaste | 打开时间轴，快捷键为 `Shift-Command-V` |
| 暂停/继续捕获 | 切换监听状态，快捷键为 `Command-T` |
| 清空未收藏历史 | 保留收藏，删除其他历史 |
| 辅助功能设置 | 打开系统权限页 |
| 退出 CPaste | 结束应用 |

## 14. 内容与来源应用

### 14.1 文本

保存完整字符串。卡片预览多行内容，详情支持文本选择。

### 14.2 链接

保存 URL 字符串，卡片突出主机名，可直接使用默认浏览器打开。

### 14.3 文件

保存一个或多个文件 URL。卡片显示文件名，详情显示完整路径；纯文本粘贴会输出路径列表。

### 14.4 图片

图片保存为本地 PNG blob，时间轴和详情均按比例预览。

### 14.5 来源应用

CPaste 在捕获时记录前台来源应用的名称和 bundle id，并显示应用图标。来源字段可以参与搜索；如果应用已卸载或系统无法读取图标，会显示应用首字母徽标。

## 15. 数据保存与隐私

默认目录：

```text
~/Library/Application Support/CPaste
```

| 路径 | 内容 |
| --- | --- |
| `history.json` | 完整文本、URL、文件路径、来源应用、时间和收藏状态 |
| `Blobs/*` | 图片和从剪贴板保存的 PDF 内容 |

CPaste 会跳过带有 concealed、transient、auto-generated 或受支持密码管理器标记的剪贴板内容。数据目录和文件仅允许当前用户访问，但内容在应用层未加密。CPaste 不包含网络上传代码。设置中的历史容量降低后会立即修剪最旧的未收藏条目。

## 16. 隔离 Demo 模式

查看完整界面且不接触正式历史：

```sh
CPASTE_STORAGE_DIR="$(mktemp -d /tmp/cpaste-demo.XXXXXX)" build/CPaste.app/Contents/MacOS/CPaste --demo
```

Demo 会生成文本、链接、文件和图片，并附带 Xcode、Safari、Finder、Preview 来源信息。

## 17. 常见问题

### 17.1 `Shift-Command-V` 没反应

- 确认 CPaste 已启动并出现在菜单栏。
- 左键点击菜单栏图标作为替代入口。
- 在设置中检查“全局快捷键可用”；若被占用，需要关闭或修改冲突应用的快捷键。

### 17.2 只能复制，不能自动粘贴

这是辅助功能权限未开启时的正常降级。点击底部橙色锁图标或设置页的“打开设置”，在系统辅助功能列表中启用 CPaste。

### 17.3 新复制内容没有出现

- 检查顶部按钮是否显示“继续捕获”，若是则点击恢复。
- 清除搜索和类型筛选。
- 切换回“历史”范围。
- 用普通文本、URL、Finder 文件或图片重新测试。

### 17.4 图片显示“预览不可用”

图片 blob 可能被外部清理。元数据仍可删除；重新复制原图片可生成新的本地 blob。

### 17.5 如何删除全部本地数据

先退出 CPaste，再删除 `~/Library/Application Support/CPaste`。此操作不可撤销，收藏内容也会一起删除。

## 19. 已知限制

- 当前为本地 ad-hoc 签名，尚未使用 Developer ID notarization。
- 自动粘贴需要用户手动授予辅助功能权限。
- 当前只保存纯字符串、URL、文件 URL 和 PNG 图片，不保存富文本/HTML 的全部原始格式。
- 当前没有 OCR、iCloud、多 Pinboard、团队共享或同步功能。
